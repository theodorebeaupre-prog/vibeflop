## 🛠 Installation Ritual

You need Python 3 and the willingness to continue.

```sh
git clone https://github.com/theodorebeaupre-prog/vibeflop.git
cd vibeflop
python3 -m http.server 8765 --bind 127.0.0.1
```

Open **http://127.0.0.1:8765**. Alternatively, open `index.html` directly, like our ancestors.

There is no `npm install`. There is no build step. There is no excuse.
